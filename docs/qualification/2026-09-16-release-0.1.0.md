# Release 0.1.0 qualification record

**Date:** 2026-09-16

**Status:** Partial pre-release qualification

This record captures evidence collected on macOS arm64 with Node.js 24.21.0
and pnpm 11.24.0 using a frozen lockfile.

## Passed evidence

- The full `pnpm check` passed: 69/69 tests, 80.32% line coverage, and 69.97%
  branch coverage.
- Standards checks and the pinned mdtheme 0.4.0 check passed.
- A packed npm CLI installed in a fresh directory outside the checkout and
  responded to version, `describe`, and a deterministic `fake-echo` invocation.
- Skills CLI 1.5.26 installed all three skills into both project and global
  locations with a temporary home, and listed the installed skills for both
  Codex and Claude targets. Native skill triggering was not tested.
- Codex 0.154.0 completed an independent review and a bounded `clamp.mjs`
  implementation using the requested native `gpt-5.6-luna` route at high
  effort through the `release-luna` alias. The intended file was the only
  observed effect, and the Node clamp test passed. The native JSONL output did
  not report runtime model identity, so that identity remains unverified.
- An explicit unavailable model request returned `route_unavailable` with exit
  code 5.
- Release Please 17.6.0, run against the actual release configuration and an
  empty manifest in a temporary fixture containing a breaking rename commit,
  produced exactly one `0.1.0` candidate.

## Incomplete evidence

- Claude Code 2.1.235 reported Claude Sonnet 5, but the invocation failed
  because the OAuth session had expired. A renewed native login is required
  before a successful Claude invocation can be recorded.
- Linux and Node.js 22 CI evidence is still required.
- The npm Trusted Publisher must be configured and matched to this repository,
  `publish.yml`, and the `npm-release` environment. Repository files cannot
  verify that external setting.
- The generated 0.1.0 release PR and tag, public npm installation, and Git
  skill installation from the versioned public source remain to be checked
  after publication.
